The right pick depends on what a mistake costs you

Every option trades API cost against wrong answers. Put a price on one mistake (a manual fix, a refund, a lost customer) and the cheapest option all-in follows. Ten seconds of someone's time at $40 an hour is about $0.11.

Use jev as the front door, not as the whole house

Read with care

  • 300 items per language: the 95% interval on one accuracy is about ±4 points, so small differences need the paired tests in the deep dive.
  • Cost covers API calls only; a model that runs locally shows $0 because hosting is not measured.
  • A classic model trained on labelled data lands -3.7 to +0.3 points from jev. jev and the LLMs worked from label names only, so with labelled data a classic model is a serious option.
  • Public benchmark data: it may be in model training data and is not client traffic.
